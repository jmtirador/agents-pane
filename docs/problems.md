## v4 (2026-10-14): fast, and works the way he expects

Source: his message on 2026-10-14 ("not very intuitive to use and its very slow ... theres no way to close it ... doing ctrl c just closes the claude window ... slow and hard to click on chats ... the way the side bar shows info just doesnt really seem super useful"), measured by a latency profiler, walked by an interaction auditor and compared with Agent of Empires, Claude Code's agent view, Claude Squad and Agent Deck by a reference scout.
Root causes, measured: the list reacts in 6-40 ms; the right side takes ~0.56 s and flashes blank on every switch (a 0.3 s wait, then a fresh `claude attach`), and Claude stops a session's process after ~1 h unattached, so the next attach boots it again.
A Rust rewrite would change none of these except ~85 ms of cold start.
